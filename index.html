🚦 Gateway Hermes
Comandos canónicos para el daemon real en macOS. Aquí la fuente de verdad es launchctl.
Estado real del gateway
sudo launchctl print system/ai.hermes.gateway | grep -E "state|pid"
Esperado: state = running y un pid activo.
Reiniciar correctamente
sudo launchctl kickstart -k system/ai.hermes.gateway
Úsalo en vez de hermes gateway restart para no mezclar LaunchAgent con LaunchDaemon.
Logs del gateway
tail -f ~/.hermes/logs/gateway-daemon.error.log
Para seguimiento en vivo de errores o crash loops.
⏰ Cron & automatizaciones
Atajos para ver jobs, filtrar fallos y ejecutar una corrida manual de prueba.
Listar todos los cron
hermes cron list --all
Incluye pausados, activos y jobs con error.
Ejecutar un job puntual
hermes cron run JOB_ID
Reemplaza JOB_ID por el ID real del job que quieras probar.
Leer jobs.json
cat ~/.hermes/cron/jobs.json
Útil para inspección rápida de provider/model, schedule y último error.
🕵️ Holmes RAG
Comandos de salud y consulta del índice ambiental local.
Estado del puente RAG
python3 ~/scripts/holmes-bridge.py --status

Consulta markdown
python3 ~/scripts/holmes-bridge.py --format markdown "compromisos zona saturada"

Buscar compromisos estructurados
python3 ~/scripts/holmes-bridge.py --compromisos "dry fog"

🖥️ Salud del Mac Mini
Atajos para mirar memoria, swap y procesos pesados cuando algo se siente lento.
Swap actual
sysctl vm.swapusage
Si el valor usado despega, hay presión real de memoria.
Top procesos
ps aux | sort -rk 3,3 | head -15
Ordena por uso de CPU para encontrar el culpable más rápido.
Espacio libre
df -h / /Users/valy
Útil antes de backups, ChromaDB o exportes grandes.
